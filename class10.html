Памятка №4

Сортировка данных

• a.sort() — сортирует исходный список на месте.

• b = sorted(a) — возвращает новый список.

• По убыванию: reverse=True.

• Сложная по лямбде: a.sort(key=lambda x: (x, -x)).

Памятка №7

Делители за SQRT(N)

import math
n = 200000
divs = set()
for d in range(1, int(math.sqrt(n)) + 1):
    if n % d == 0:
        divs.add(d)
        divs.add(n // d)
