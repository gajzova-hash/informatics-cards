Динамическое программирование (Задание 16)

Для ускорения рекурсии (чтобы избежать RecursionError и зависаний) используйте кэширование.

from functools import lru_cache
import sys

# Снимаем лимит на глубину рекурсии
sys.setrecursionlimit(10000)

@lru_cache(None)
def f(n):
    if n <= 1: return 1
    if n % 2 == 0: return n + f(n - 1)
    return 2 * f(n - 2)

Теория игр: Одна куча (Задание 19-21)

Универсальный шаблон для анализа ходов Пети и Вани с помощью рекурсивной функции.

def game(s, m):
    # s - камни, m - доступные ходы
    if s >= 50: return m % 2 == 0
    if m == 0: return False
    
    # Список возможных ходов из кучи s
    moves = [game(s + 1, m - 1), 
             game(s * 2, m - 1)]
             
    # Четный шаг - наш ход, нечетный - соперника
    if (m - 1) % 2 == 0:
        return any(moves) # Ищем выигрышный ход
    return all(moves) # Проверяем все ходы

Теория игр: Две кучи (Задание 19-21)

Модификация шаблона под стратегию игры, когда на столе находятся сразу две кучи камней.

def game(x, y, m):
    if x + y >= 77: return m % 2 == 0
    if m == 0: return False
    
    moves = [game(x + 1, y, m - 1),
             game(x * 2, y, m - 1),
             game(x, y + 1, m - 1),
             game(x, y * 3, m - 1)]
             
    if (m - 1) % 2 == 0:
        return any(moves)
    return all(moves)

Поиск путей в графах (Задание 13/23)

Алгоритм подсчета количества путей из стартовой вершины `A` в конечную вершину `B` по правилам команд.

def count_ways(current, target):
    if current > target: return 0
    if current == target: return 1
    
    # Пример команд исполнителя: +1, +2, *2
    return (count_ways(current + 1, target) + 
            count_ways(current + 2, target) + 
            count_ways(current * 2, target))

• Обязательные точки перегиба считаем как: ways(A, C) * ways(C, B)

Генерация масок файлов (Задание 25)

Использование встроенной стандартной библиотеки `fnmatch` для фильтрации чисел по маске.

from fnmatch import fnmatch

# Маска: знак '?' - один символ, '*' - любое кол-во
mask = '12?4*5'

for x in range(0, 10**7, 21): # Шаг делителя
    if fnmatch(str(x), mask):
        print(x, x // 21)

Перебор числовых диапазонов (Задание 17)

Поиск пар элементов в списке, удовлетворяющих сложным логическим критериям.

a = [int(x) for x in open('17.txt')]
max_item = max(x for x in a if x % 100 == 13)
ans = []

for i in range(len(a) - 1):
    # Проверка условий для пары a[i] и a[i+1]
    if (a[i] % 2 == 0) != (a[i+1] % 2 == 0):
        if (a[i] + a[i+1]) <= max_item:
            ans.append(a[i] + a[i+1])

print(len(ans), max(ans))

for a in range(1, 1000):

f = open('26.txt')
# Читаем общие параметры из первой строки
capacity, n = map(int, f.readline().split())

box = sorted([int(x) for x in f])
total, count = 0, 0

# Генерация пар координат (x, y) от -10 до 10
points = [(x, y) for x in range(-10, 11) 
                 for y in range(-10, 11)]
