Памятка №1

Ввод данных Python

s = input()  # Текст

Имя переменной: латиница, цифры (не первыми), знак `_`.

Памятка №2

Вывод данных (print)

print(x, y) # Через пробел
print(a, b, sep='-') # Свой сепаратор
print(x, end=' ') # Без новой строки
print(f'Мне {age} лет') # F-строка

Памятка №3

Арифметика Python

• / — деление (результат всегда float, 4 / 2 == 2.0).

• // — деление нацело (округление вниз, 7 // 3 == 2).

• % — остаток от деления нацело (7 % 3 == 1).

• ** — возведение в степень (2 ** 3 == 8).

➕
Памятка №4

Сравнения и bool

• Возвращают True или False.

• Операторы: >, <, >=, <=.

• == — проверка на равенство. != — проверка на неравенство.

Памятка №5

Ветвления (if-else)

if x > 0:
    print('Плюс')
elif x < 0:
    print('Минус')
else:
    print('Ноль')

ВАЖНО: После условий ставится `:`, отступы в 4 пробела!

🔱
Памятка №6

Логические операторы

• and (И) — истинно, если ВСЕ условия верны.

• or (ИЛИ) — истинно, если ХОТЯ БЫ ОДНО верно.

• not (НЕ) — инвертирует логику (if not flag:).

Памятка №7

Цикл while

i = 1
while i <= 3:
    print(i)
    i += 1  # Изменение счетчика!

Выполняется, пока условие истинно.

Памятка №8

Цикл for и range()

• range(5) → 0, 1, 2, 3, 4 | range(1, 5) → 1, 2, 3, 4

• range(1, 10, 2) → 1, 3, 5, 7, 9 (с шагом)

• Обратный ход: range(5, 0, -1) → от 5 до 1.

🔁
Памятка №9

break и continue

• break — немедленный полный выход из текущего цикла.

• continue — пропуск остатка кода тела цикла и переход к следующей итерации.

🛑
Памятка №10

Списки (list)

• Коллекция элементов. Создание: arr =

• Индексы с 0: arr → 10. С конца: arr[-1] → 30.

• Несуществующий индекс вызовет IndexError.

📦
Памятка №11

Методы списков

• arr.append(x) — добавить x в конец.

• arr.insert(i, x) — вставить x на индекс i.

• arr.pop() — удалить и вернуть последний (или по индексу pop(i)).

• len(arr) — количество элементов.

🛠️
Памятка №12

Срезы (Slices)

• Шаблон: коллекция[start:stop:step]

• arr[1:4] — индексы от 1 до 3. arr[:3] — от начала до 2.

• arr[::-1] — разворот списка/строки задом наперед!

✂️
Памятка №13

Перебор списка

# Способ 1 (без индексов):
for elem in arr:
    print(elem)

# Способ 2 (по индексам):
for i in range(len(arr)):
    print(arr[i])
🚶
Памятка №14

Строки (str)

• Текст (неизменяемый тип).

• Конкатенация: 'Пит' + 'он' → 'Питон'

• Дублирование: 'А' * 3 → 'AAA'

• Поиск подстроки: if 'ит' in 'Питон': (True)

• Длина текста: len('Привет') → 6.

🔤
Памятка №15

Методы строк

• s.upper() / s.lower() — перевод регистра.

• s.count(sub) — подсчет вхождений подстроки.

• s.find(sub) — индекс первой подстроки (или -1).

• s.replace(old, new) — замена текста.

🔠
Памятка №16

split и join

• s.split() — режет строку по пробелам в список строк.

• sep.join(list) — собирает список в строку через разделитель sep: '-'.join(['А', 'Б']) → 'А-Б'.

Генераторы списков

# Квадраты от 0 до 4:
squares = [x**2 for x in range(5)]

Памятка №18

Встроенные мат. функции

• abs(x) — модуль | round(x, 2) — округление.

• min(arr) / max(arr) — поиск минимума/максимума в списке.

• sum(arr) — сумма всех элементов числового списка.
